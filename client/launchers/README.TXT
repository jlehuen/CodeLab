[ Windows ]
1) Decompressez ce dossier a l'emplacement de votre choix.
2) Double-cliquez sur "install.bat" pour creer le raccourci sur votre Bureau.
3) Vous pouvez lancer CodeLab depuis le Bureau ou en double-cliquant sur "codelab.exe".

[ Linux ]
1) Decompressez ce dossier a l'emplacement de votre choix.
2) Executez "./first_time.sh" pour ajouter CodeLab a votre menu et Bureau.
3) Vous pouvez lancer CodeLab depuis votre menu d'applications ou via "./codelab".
