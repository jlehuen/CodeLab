# Grille d'Évaluation : Java / POO (Modèle d'exemple)

| Axe d'évaluation | Barème | Critères d'observation |
| :--- | :---: | :--- |
| **Axe 1 : Compilation Java** | / 6 pts | Absence d'erreur de compilation `javac`, respect de la structure des packages et noms de fichiers. |
| **Axe 2 : Modélisation Objet & Encapsulation** | / 8 pts | Attributs `private`, méthodes publiques cohérentes, constructeurs explicites, découpage des responsabilités. |
| **Axe 3 : Javadoc & Conventions Java** | / 4 pts | Commentaires Javadoc `/** ... */` sur classes et méthodes, nommage `camelCase`, constantes en majuscules. |
| **Axe 4 : Démarche de test** | / 2 pts | Classes ou méthodes de test, assertions `assert` ou vérification de sorties. |
| **Total** | **/ 20 pts** | Note globale formative. |
