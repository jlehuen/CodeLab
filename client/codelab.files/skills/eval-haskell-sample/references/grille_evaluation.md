# Grille d'Évaluation : Haskell / Programmation Fonctionnelle (Modèle d'exemple)

| Axe d'évaluation | Barème | Critères d'observation |
| :--- | :---: | :--- |
| **Axe 1 : Compilation & Typage GHC** | / 6 pts | Compilation et vérification de types sans erreur (`ghc -fno-code`) sur les fichiers `.hs` et carnets `.ipynb` Haskell. |
| **Axe 2 : Conception Fonctionnelle** | / 8 pts | Signatures de types explicites (`::`), récursivité, filtrage par motif, gardes, types algébriques et fonctions d'ordre supérieur (`map`, `filter`, `fold`). |
| **Axe 3 : Style & Exhaustivité** | / 4 pts | Absence de warnings `-Wall` (motifs incomplets, liaisons inutilisées), commentaires/Haddock, nommage idiomatique et absence d'anti-patterns (`head`/`tail` partiels). |
| **Axe 4 : Démarche de Test** | / 2 pts | Présence de tests explicites (`test*`, propriétés `prop_*` / QuickCheck, assertions ou `main` de validation). |
| **Total** | **/ 20 pts** | Note globale formative. |
