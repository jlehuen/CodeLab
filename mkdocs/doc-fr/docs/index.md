## Références des API par langage

- [**Langage C**](lang-c/doc-c-fr.md) : Bibliothèque graphique 2D, gestion des robots Lego NXT, servomoteurs et utilitaires système.
- [**Langage Java**](lang-java/doc-java-fr.md) : Classes pédagogiques (`Drawing`, `Turtle`, `RobotLego`, `NXTMotor`, `EventManager`, etc.).
- [**Langage Python**](lang-python/doc-py-fr.md) : Modules `graph2D`, `turtle`, `robotLego`, `robotRovio`, `nxtMotor`, `sound` et `system`.
- [**Langage CLIPS**](lang-clips/doc-clips-fr.md) : Primitives de raisonnement à base de règles pour les graphiques et la robotique.
